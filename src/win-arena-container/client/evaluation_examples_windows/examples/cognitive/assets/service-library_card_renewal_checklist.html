Library card services

Requirements differ for renewals, replacements, and youth applications. Use the section that matches your service.

Renew an existing adult card — in person

Bring a photo ID.

Bring proof of current address dated within the last 90 days.

The renewal desk closes at 5:30 PM.

Use renewal desk code LR-27.

Replace a lost adult card

Bring a photo ID and the $4 replacement fee.

Replacement desk closes at 6:00 PM.

Use desk code RP-14.

Apply for a youth card

Bring proof of age and a parent or guardian ID.

Youth services closes at 4:30 PM.

Use desk code YT-08.

Online renewal is unavailable for expired cards; visit the renewal desk instead.
